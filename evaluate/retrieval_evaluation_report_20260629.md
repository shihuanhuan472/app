# 维护辅助系统检索与问答评估报告

评估日期：2026-06-29

## 1. 评估范围

本次报告汇总文本检索/问答评估与图像检索评估结果。

| 评估类型 | 结果来源 | 样本数 | 说明 |
| --- | --- | ---: | --- |
| 文本检索与问答评估 | `evaluate/company_demo_20260628_111130/summary.json` | 387 | 基于 SQL 已解析文档生成文本问答测试集，评估检索、上下文质量和答案准确性 |
| 图像检索评估 | `evaluate/retrieval_eval_20260628_121116/retrieval_summary.json` | 161 | 基于带图片文档生成图像检索测试集，评估图像输入下正确文档的召回和排序 |

评估脚本默认直接调用项目现有检索流程：

```text
get_reference_documents()
-> VectorService.search_similar_documents()
-> vector_store_multimodal.search()
-> 关键词/领域词补召回
-> 分数调整
-> chunk 合并为文档
-> 阈值过滤并返回 Top 文档
```

该方式与系统实际检索核心路线一致，同时避免通过 `/message/ask` 写入评估对话数据。

## 2. 检索效果对比

| 指标 | 文本检索 | 图像检索 | 说明 |
| --- | ---: | ---: | --- |
| 样本数 | 387 | 161 | 参与评估的 case 数 |
| Top-1 命中率 | 81.91% | 86.34% | 标准文档排在第 1 位的比例 |
| Top-K 召回率 | 92.76% | 95.65% | 标准文档出现在返回结果中的比例 |
| MRR | 87.12% | 90.58% | 正确文档排序越靠前，分数越高 |
| 未命中数量 | 28 | 7 | 未检索到标准文档的 case 数 |
| 平均返回文档数 | 2.509 | 3.000 | 每个问题平均返回的参考文档数量 |

结论：图像检索和文本检索均能稳定召回正确文档。图像检索 Top-1、Top-K 和 MRR 均高于文本检索，说明在当前图像测试集上，正确文档通常能够被检索到并排在较靠前的位置。

## 3. 文本问答质量

| 指标 | 结果 | 含义 |
| --- | ---: | --- |
| 答案生成率 | 100.00% | 387 条 case 均生成了答案 |
| 通过率 | 88.89% | 344 / 387 条答案达到通过阈值 |
| context precision | 75.63% | 检索上下文的相关性和排序质量 |
| context recall | 82.25% | 检索上下文对标准答案事实的覆盖程度 |
| faithfulness | 91.65% | 生成答案是否被检索上下文支持 |
| answer accuracy | 87.62% | 生成答案相对标准答案的正确性 |

文本问答整体表现较好。`faithfulness` 达到 91.65%，说明答案大多基于检索上下文生成，编造风险较低；`answer_accuracy` 为 87.62%，说明最终回答与标准答案的一致性较强。

`context precision` 相对较低，主要与 chunk 较大、返回上下文中包含额外信息有关。只要上下文包含关键事实，大模型通常仍能回答正确，但该指标会受到无关上下文比例影响。

## 4. 图像检索排序指标

| 指标 | 结果 | 含义 |
| --- | ---: | --- |
| Precision@K | 31.88% | 返回的前 K 个文档中，相关文档所占比例 |
| Recall@K | 95.65% | 所有标准相关文档中，被检索到的比例 |
| F1@K | 47.83% | Precision 和 Recall 的调和平均 |
| MRR | 90.58% | 第一个相关文档越靠前，分数越高 |
| MAP | 90.58% | 综合评估相关文档排序质量 |

图像检索的 `Recall@K` 达到 95.65%，说明大多数图像 case 能找回标准文档；`MRR` 和 `MAP` 均为 90.58%，说明正确文档通常排在靠前位置。

`Precision@K` 为 31.88%，不代表效果差。当前图像测试集默认每条 case 只有 1 个标准相关文档，而系统平均返回 3 个文档，因此 Precision@3 的理论上限约为：

```text
1 / 3 = 33.33%
```

当前 31.88% 已接近该设置下的理论上限。

## 5. 综合结论

本次评估表明，维护辅助系统在文本和图像两类输入下均具备较稳定的知识召回能力：

| 能力项 | 结论 |
| --- | --- |
| 文本检索 | Top-K 召回率 92.76%，多数问题能找回标准文档 |
| 文本问答 | 答案准确性 87.62%，忠实度 91.65%，整体可用于企业知识问答展示 |
| 图像检索 | Top-K 召回率 95.65%，MRR 90.58%，图像输入下正确文档排序靠前 |
| 风险点 | 文本上下文精度仍有提升空间，主要受大 chunk 和额外上下文影响 |

面向公司展示时，建议重点展示以下指标：

| 展示重点 | 推荐指标 |
| --- | --- |
| 文本问答效果 | answer accuracy 87.62%、faithfulness 91.65% |
| 文本检索效果 | Top-1 81.91%、Top-K 92.76%、MRR 87.12% |
| 图像检索效果 | Top-1 86.34%、Recall@K 95.65%、MRR 90.58%、MAP 90.58% |

总体来看，系统已经具备较好的多模态检索和问答能力，图像检索召回表现尤其稳定；后续优化重点可放在文本检索上下文精度提升、chunk 粒度调整和低分 case 定向分析上。

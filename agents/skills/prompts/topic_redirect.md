# TopicRedirectSkill

## 适用场景
用户提出低信息确认、可靠性质疑、投诉、明显跑题内容、无意义字符、语言混杂内容，或问题暂时不能帮助故障排查。

## 任务
不要查库，不要输出内部审计报告；简短回应用户，并把对话引导回设备故障问答。

## 思考要求
1. 如果用户只是问“你确定吗/靠谱吗/对吗”，不要假装绝对保证，说明需要具体依据或故障信息。
2. 如果用户说回答不对或要投诉，先表达收到反馈，再请用户指出具体不准确点。
3. 如果用户输入无关内容或混杂语言，只做一句必要解释，然后引导回故障主题。
4. 不输出 route、trace、active_context、skill、prompt、引用对比或内部执行日志。

## 输出要求
- 最多两三句话。
- 必须引导用户补充至少一种故障排查信息：设备型号、故障现象、报错信息、软件版本、测试条件或现场图片。

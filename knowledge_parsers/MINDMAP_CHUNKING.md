# 脑图切块

## 长图 OCR

`mindmap_parser.ocr_blocks` 对最长边超过 2000 像素的图片使用原尺寸重叠
切块（默认块边长 1536、重叠 256）；宽度不超过 2000 的长图保留全宽。
切块不做缩放，OCR 坐标加裁剪起点后统一到原图；连线仍在完整原图上识别。
重叠检测按原图位置去重，优先保留不贴人工边界的完整文字框，不按文字内容
全局去重，因此不同位置的同名节点仍保留。

人工边界附近的框会从原图扩大裁剪补识别（两档边距 128 / 384，裁剪最长边
不超过 2000）。无法恢复的框保留 `boundary_clipped: true`，其索引写入
`diagnostics.boundary_clipped_nodes`；分类通过时结果状态为 `needs_review`。
重叠与有限补识别不能保证恢复任意超长标签，应复核这些标记。

## 知识切块

结构恢复保留连线检测的父子方向，拒绝环路和冲突父节点。矩形节点使用边框
连接口，根节点额外支持顶部、底部出线。断连部分只按有向子树根临时展示，
标记 `flag: detached`，不反转边，不参与知识切块。Markdown 明示待确认连接。
`root_reachable_ratio` 只统计真实连线从根可达的节点，`root_child_count`
只统计真实一级分支；临时挂根不计入这些指标。

`mindmap_chunker.chunk_mindmap(tree, source_file=..., source_version=...)`
接收解析器的 `{tree_id, root, _meta}`，返回 path / branch 两类字典。

- path：每条根到叶子的完整链路，兄弟分支分开保存。
- branch：有两个及以上可信直接子节点的位置，包含完整上游和各个子分支。
- 不按固定字数切分，不生成孤立 node 块，不根据深度推断条件或措施。
- 保留 tree_id、node_id、node_ids、path_nodes、parent_id、来源和版本。
  缺失节点 ID 时按结构位置生成；重复 ID、空文本显式报错。
- OCR 人工挂根的 orphan / detached 节点及其子树不参与诊断切块，
  原树继续保留，复核修正连接后应移除对应 flag 和 _meta 标记并重新索引。

文档解析时在章节 `metadata.image_parsing` 中保留原始树及切块，导出
`.tree.json` 和 `.chunks.json`。向量化时根据当前树重新生成切块，
通过现有知识库版本及章节元数据关联原树。文本以纯文本方式生成向量，
不会对每条路径重复调用整张图片的多模态编码。

现有普通章节文本和表格切块继续保留。脑图块超过现有存储安全容量或
7800-token 输入预算时显式失败，避免静默截断末尾链路；应拆分超长节点
中的说明后重试。大元数据可省略重复链路详情，但保留树/节点/章节定位键。

检索命中后，调用方可根据版本、section_id、source_image_url、tree_id、
node_id 回查原始树。自动沿树追问、条件冲突核对不属于本切块模块，
不能仅凭路径相似度认定尚未确认的分支条件。

已有文档需要重新解析并执行原有向量更新流程才会生成这些块。

验证：`python tests/test_mindmap_chunker.py`。
